Conozco el contenido de tu C2 con los 3 ejercicios que trabajaste. Puedes preguntarme cualquier cosa del material.

Para empezar: ¿con qué tema quieres trabajar hoy? ¿Y puedes explicarme con tus propias palabras qué representa f'(x)?

📚 Resumen de Estudio — C2 Cálculo

📈 Máximos y Mínimos

  • Calcular f'(x) e igualar a cero
  • Puntos críticos: f'=0 o f' no existe
  • Criterio 1° derivada: tabla de signos
  • Criterio 2° derivada: f''(c) < 0 → máximo
  • f''(c) > 0 → mínimo local
  • Creciente donde f'(x) > 0

〰️ Concavidad e Inflexión

  • Calcular f''(x)
  • f'' > 0 → cóncava hacia arriba (U)
  • f'' < 0 → cóncava hacia abajo (arco)
  • Inflexión: f''=0 Y cambia de signo
  • Calcular f(x) en el punto inflexión
  • Ejemplo: x=-1/2 en Ejercicio 1

🎯 Optimización

  • Definir variable x y dominio
  • Escribir función objetivo f(x)
  • Derivar e igualar a cero
  • Clasificar con criterio 2° derivada
  • Calcular e interpretar valor óptimo
  • Ej: A(x)=120x-2x² → máximo x=30

∫ Integral Indefinida

  • Primitiva: F'(x) = f(x)
  • x^n → x^(n+1)/(n+1) + C
  • Constante +C siempre
  • Sustitución: u=g(x), du=g'(x)dx
  • Verificar derivando el resultado
  • ∫e^x dx = e^x + C
📝 Ejercicios C2 — Resultados clave
Ejercicio 1 — f(x) = x^2 / (x-1)^2
Dom = R-{1} | Mínimo: (0,0) | Asínt. vert: x=1 | Asínt. horiz: y=1
Inflexión: (-1/2, 1/9) | Creciente (0,1) | Decreciente (-inf,0) U (1,+inf)
Ejercicio 2 — A(x) = 120x - 2x², con 0 < x < 60
A'(x) = 120-4x = 0 → x=30 m | A(30) = 1800 m² (máximo)
Con x=20: A(20)=1600 m² → 11.11% menor que el máximo
Ejercicio 3 — C(x)=1500+20x+2x²+x³/3 | p(x)=1160-2x
I(x) = 1160x-2x² | U(x) = 1140x-4x²-1500-x³/3
U'(x)=0 → x=30 sensores | U(30)=20.100 dólares | I'(30)=C'(30)=1040
📐 Formulario de Cálculo
Derivación
Potencia
d/dx [x^n] = n * x^(n-1)
Regla del cociente
(f/g)' = (f'g - fg') / g^2
Regla de la cadena
(f(g(x)))' = f'(g(x)) * g'(x)
Exponencial y Logaritmo
d/dx [e^x] = e^x | d/dx [ln x] = 1/x
Criterios para Extremos
Criterio 1° Derivada
f'(c)=0 → punto crítico. (+) a (-): máximo | (-) a (+): mínimo
Criterio 2° Derivada
f''(c) > 0 → mínimo | f''(c) < 0 → máximo | f''(c)=0 → no concluye
Asíntotas
Vertical x=a
lim(x→a) f(x) = ±∞
Horizontal y=L
lim(x→±∞) f(x) = L
Integrales
Potencia
∫ x^n dx = x^(n+1)/(n+1) + C (n ≠ -1)
Logaritmo y Exponencial
∫ 1/x dx = ln|x| + C | ∫ e^x dx = e^x + C
Trigonométricas
∫ cos(x) dx = sin(x) + C | ∫ sin(x) dx = -cos(x) + C
Sustitución simple
u=g(x), du=g'(x)dx → ∫f(g(x))g'(x)dx = F(g(x)) + C
